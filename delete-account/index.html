Sample App 계정 삭제 안내

계정을 만들 수 있는 앱은 앱 안과 웹에서 계정 삭제 요청 경로를 제공해야 합니다. 이 페이지는 Google Play 계정 삭제 URL에 넣을 수 있는 웹 리소스 예시입니다.

삭제 요청 방법

  1. support@example.com으로 계정 삭제 요청을 보냅니다.
  2. 요청 메일에 앱 이름, 가입 이메일, 본인 확인에 필요한 정보를 포함합니다.
  3. 확인 후 계정과 연결된 데이터를 삭제하고 처리 결과를 안내합니다.

삭제되는 데이터

계정 정보, 앱 내 저장 데이터, 사용자 식별자와 연결된 서비스 데이터를 삭제합니다. 법령상 보관이 필요한 결제 또는 분쟁 대응 기록은 별도 보관 후 기간 만료 시 삭제할 수 있습니다.

처리 기간

삭제 요청은 접수 후 30일 이내 처리를 목표로 합니다.
